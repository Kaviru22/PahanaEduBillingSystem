# Pahana Edu Online Billing System

## Overview  
A Java web-based billing system using JSP, Servlets, and PostgreSQL designed for managing users, customers, items, and billing.

## Repository  
[GitHub Repo](https://github.com/Kaviru22/PahanaEduBillingSystem)  

## Setup Instructions  
1. Clone: `git clone https://github.com/Kaviru22/PahanaEduBillingSystem.git`  
2. Navigate to project folder and build: `mvn clean install`  
3. Deploy the generated WAR to Apache Tomcat  
4. Initialize database using `db/schema.sql`  
5. Access via `http://localhost:8080/PahanaEduBillingSystem/login.jsp`
